# Project Name: Picture Hub - an Idea from Instagram

  ## Functionalities Added
    - Register User
    - Login User
    - Logout User
    - See all posts
    - Likes / Comments on all users posts
    - Follow / Unfollow any user
    - Create own post
    - See suggested users
    - Profile Changes - Profile Picture, Bio, Username, First Name, Last Name, Location.
    
  ## Stack Used
    - Mongo - DB
    - React - UI/ Frontend
    - Express - Server
    - Node - Backend
